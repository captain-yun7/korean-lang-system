## 결정 사항
- 응시 연결은 "배정 레코드 자동 생성" 방식(B안) 채택 — 기존 응시/제출/채점/결과 조회 흐름을 그대로 재사용, 제출·채점 코드는 무변경
- `assignedBy`는 `'SHARE_LINK'` 문자열로 기록 — `Exam`에 작성 교사 필드가 없고, `assignedBy`는 코드에서 읽는 곳이 없는 기록용 필드라 출처 구분 값으로 사용
- 이미 배정이 있으면 재사용(교사가 설정한 마감일·재응시 조건을 덮어쓰지 않음)
- 자동 배정의 재응시 규칙은 시험지 자체 `maxAttempts` 설정을 따름

## 이슈 & 해결
- 학생 제보: 카톡 공유 링크 클릭 후 로그인하면 문제 푸는 창이 안 나옴
  - 원인: 공유 페이지가 미리보기 전용 + 로그인 버튼에 callbackUrl 없음 → 로그인하면 대시보드로 이동하는데, 배정되지 않은 시험이라 목록에도 없음
  - 해결: 위 claim 흐름으로 링크 → 로그인 → 바로 응시 연결
- `npx tsc --noEmit` 기존 에러 38개 존재 (여러 API 라우트의 `params`가 Next.js 15+ Promise 타입과 불일치). 이번 변경과 무관해 보류
